## 运行

在微信开发者工具中单独导入 `cloud-version/`，不要把根目录本地版当作云端版导入。检查项目 AppID 和 `config/cloud.js` 中的环境 ID；云函数部署、数据库及存储配置仍需在自己的云环境中完成。本批没有部署云服务或更新体验版，本地检查通过不代表现有云环境可用。需要离线演示时可继续导入仓库根目录使用本地版。

## 隔离与安全

- 根目录本地版的页面和存储逻辑保持不变，根项目打包时排除本目录及本机的原云端源目录。
- 不包含嵌套 Git 仓库、依赖安装目录、开发者私人配置或凭证。
- 本目录是代码交付，不会自动修改已部署云函数、数据库权限或现有体验版。
- 云环境 ID 与 AppID 是项目标识，不是密钥；独立部署到其他小程序时需要使用自己的 AppID 和云环境。
