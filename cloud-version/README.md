## 运行与部署

1. 在微信开发者工具中单独导入 `cloud-version/`；根目录导入的是本地版。
2. 检查 `project.config.json` 的 AppID，若不属于自己的账号则替换。启用云开发，并检查 `config/cloud.js` 中的环境 ID。
3. 在对应云环境中准备 `items`（物品）、`favorites`（收藏）、`users`（展示资料）、`reports`（反馈）四个集合。客户端不直接读写集合，数据库应仅允许云函数访问；不要为了图片显示开放整个数据库或存储权限。
4. 右键 `cloudfunctions/shiguangApi`，选择“上传并部署：云端安装依赖”，完成后重新编译或预览。`wx-server-sdk` 依赖由云端安装。首次启动的初始化会写入 5 条演示信息；只在自己授权的环境运行。
5. 若使用体验版，重新上传并更新体验版，手机端再验证最新代码。已有体验版不会因为 GitHub 更新而自动变化。

本轮迁移没有部署云服务、修改权限、写入真实测试数据或更新体验版。源项目历史部署情况不能代替本目录当前部署验证。需要离线演示时可继续导入仓库根目录使用本地版。

## 图片与错误处理

照片发布前上传到云存储，数据库保留稳定的云文件 ID；云函数只为已查出的物品照片生成短期链接。图片失败不会把真实存在的物品变成“不存在”，详情页提供图片重试。详情请求区分加载中、网络错误和明确的空结果；网络错误可重试，较早的慢请求不能覆盖后一次请求。更新这些功能必须同时重新部署云函数和更新客户端。
